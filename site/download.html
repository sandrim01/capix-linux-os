Baixar o Capix Linux OS

Versão AMD/Intel · ~5 GB · instalador que pergunta o disco

📦 O GitHub limita cada arquivo a 2 GB, então a ISO vem em 3 partes. É só baixar as três, juntar num arquivo só com um comando e gravar. Parece trabalhoso, mas são 2 minutos.
1

Baixe as 3 partes

Salve todas na mesma pasta (ex.: Downloads).

2

Junte as partes numa ISO só

Abra o terminal na pasta onde estão as partes e rode o comando do seu sistema.

copy /b capix-amd-intel.iso.part00.bin+capix-amd-intel.iso.part01.bin+capix-amd-intel.iso.part02.bin capix.iso
cat capix-amd-intel.iso.part*.bin > capix.iso
3

Confira se juntou certo (opcional)

O código abaixo (SHA-256) deve bater com o da sua ISO.

7b1ea18c658480d44212bf5793ed9475b8364e9fee44972fb477a309f192b49a
Windows: certutil -hashfile capix.iso SHA256 · Linux/macOS: sha256sum capix.iso
4

Grave e instale

Grave a capix.iso num pendrive com o Rufus ou o balenaEtcher (modo imagem/DD). Dê boot pelo pendrive — o instalador pergunta em qual disco instalar, e nada é apagado sem você escolher. Ao terminar, remova o pendrive e reinicie.

🟢 Placa NVIDIA

Instale a versão acima normalmente. Depois, troque para a imagem com o driver NVIDIA proprietário já embutido — um comando no terminal do Capix:

sudo bootc switch ghcr.io/sandrim01/capix-nvidia:44
